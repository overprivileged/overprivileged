## 👋 Hey, I'm Overprivileged

AI tools and AI-built apps now touch your files, your photos and your screen. Most of them get **way more access than they need**. That's where the name comes from.

So I install them on my own Mac, **try to break them**, read the code and the docs nobody reads, and tell you in plain English what's actually safe, what isn't, and what to change.

- 🔬 **I test the apps you download**: network watches, reverse engineering, escape attempts
- 🛰️ **I watch open-source projects**: how fast they change, what gets fixed, what reaches you
- 🤖 **AI and security, plainly**: what an AI can really touch, and how attacks work
- 🛠️ **I fix things too**: bugs I find go to the developers, with a fix when I can

**No hype, no hate.** Real tests, real mistakes (I leave them in), honest results. If a test can't prove something, I say so.

## 🧪 How I test
1. **Real installs** on my own Mac, with **fake data** only.
2. I **try to break it**, and the attempts stay in the video, mistakes included.
3. I **only claim what the recordings and the data show**, and I say what a test can't prove.
4. Found a real problem? I tell the developers first, and send a fix when I can.
